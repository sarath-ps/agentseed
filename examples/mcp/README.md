# MCP Examples

Example Model Context Protocol configurations for AgentSeed projects.

These are **starting points**. Adjust commands, paths, and permissions for your environment and agent runtime (Cursor, Claude Code, Codex, etc.).

## Files

| File | Intent |
|------|--------|
| `cursor-mcp.example.json` | Example Cursor-style MCP config |
| `recommended-servers.md` | Short descriptions of useful servers |

## Usage

1. Copy the example that matches your tool.
2. Rename / place it where your agent expects MCP config.
3. Enable only the servers you need.
4. Restart or reload the agent so it picks up the new servers.
