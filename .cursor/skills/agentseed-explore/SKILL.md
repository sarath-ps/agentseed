# AgentSeed Explore

Clarify intent and explore an idea before creating a formal change proposal.

## When to use

When the user is unsure about scope, requirements, or direction. Good first step before `/agentseed-propose`.

## Behaviour

1. Ask clarifying questions if needed.
2. Read relevant existing specs under `agentseed/specs/`.
3. Summarise understanding and surface open questions.
4. Suggest whether a formal change proposal is warranted.
