# Minimal AgentSeed Template

A clean starting point that already contains:

- `AGENTS.md`
- `.agents/skills/` (symlink or copy from the main AgentSeed repo recommended)
- `agentseed/specs/`, `agentseed/changes/`, `agentseed/party/`

## Getting Started

1. Copy this folder (or the whole AgentSeed repo) as the base of your new project.
2. Ensure skills are available under `.agents/skills/`.
3. Read `AGENTS.md` and begin with `/party ideation` or the explore → propose workflow.
