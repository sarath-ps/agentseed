# AgentSeed Templates

Starter project layouts that already include the AgentSeed structure (`AGENTS.md`, `.agents/skills/`, `agentseed/` folders, etc.).

## Available Templates

| Template | Description |
|----------|-------------|
| `minimal` | Bare-bones starting point with the core AgentSeed layout |
| `polyglot-monorepo` | Polyglot monorepo skeleton suitable for microservices (frontend + backend + shared + infra) |

## Usage (manual for now)

1. Copy the desired template directory into a new project location.
2. Rename / adjust as needed.
3. Start using the skills and Party Mode immediately.

A future `agentseed init` CLI will automate this.
