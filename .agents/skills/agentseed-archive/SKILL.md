# AgentSeed Archive

Merge accepted change deltas into the living specs under `agentseed/specs/` and archive the change.

## Behaviour

1. Apply accepted delta content into the corresponding living `spec.md` files.
2. Move the change directory to `agentseed/changes/archive/` (create the folder if needed).
3. Confirm the living specs are now the source of truth.
4. Leave a short note of what was archived.

## Output

- Specs updated
- Archive path
- Any follow-up items
