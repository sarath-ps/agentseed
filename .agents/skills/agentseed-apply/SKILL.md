# AgentSeed Apply

Implement the tasks from an approved change under `agentseed/changes/<change-id>/`.

## Behaviour

1. Read `proposal.md`, `design.md`, and `tasks.md`.
2. Implement only the approved scope.
3. Prefer small, reviewable commits / edits.
4. Update task status in `tasks.md` as work progresses.
5. Call out any needed design deviations instead of silently expanding scope.

## Output

- What was implemented
- Remaining tasks (if any)
- Notes for Verify
