# AgentSeed Explore

Clarify intent and explore an idea before creating a formal change proposal.

## When to use

When the user is unsure about scope, requirements, or direction. Good first step before `/agentseed-propose`.

## Behaviour

1. Ask clarifying questions if needed (problem, users, constraints, success criteria).
2. Read relevant existing specs under `agentseed/specs/` and any related code.
3. Summarise current understanding in plain language.
4. Surface open questions, risks, and assumptions.
5. Recommend whether to proceed to a formal change proposal (and what the change-id might be).

## Output

- Short problem framing
- Key constraints
- Open questions
- Suggested next step (explore further vs propose)
